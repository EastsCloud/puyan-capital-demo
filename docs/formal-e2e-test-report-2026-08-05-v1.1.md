# Isater v1.1 正式端到端点击测试报告

测试结论：**主业务流程已通过真实页面点击跑通；日期一致性问题已修复并完成针对性真实点击回归。**

## 1. 测试原则

- 使用全新的独立测试数据库，不复用旧流程状态。
- 所有业务推进均通过页面可见按钮、表单和角色登录完成，没有使用地址跳转代替操作。

## 6. 已解决问题

### E2E-20260805-01 非股票净值日期未按录入日期保存

- 状态：已解决。
- 根因核对：原始审计记录显示页面实际提交值为 2026-08-05；数据库和报告没有篡改日期。问题在于页面默认使用当天日期，并允许它与最新有效持仓日期不一致，操作者容易漏改。
- 修复：非股票净值日期自动取最新有效股票持仓日期并设为只读；后台再次强制校验两者必须相同；页面、接口和审计记录统一输出 `YYYY-MM-DD`。
- 周期修复：报告发布后再次进入非股票净值环节时，即使上一版本已经批准，系统也会开放新一期净值版本录入。
- 回归结果：页面自动显示 2026-08-10；执行人员提交的 v2、委员会审批页、审计记录和新生成报告的截止日均为 2026-08-10。
