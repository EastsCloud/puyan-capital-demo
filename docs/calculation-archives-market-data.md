# 计算复核、档案回收站和行情同步

开发日期：2026-11-02。本次已完成本地开发与验证，线上部署状态需另行核实；未对线上档案执行删除，也未使用真实行情凭证执行全市场同步。

## 1. 优先：收益率与Beta的计算过程

Sleeve页面将Beta明确标为“目标Beta（CAPM）”，并可展开原始分解目标、原始市场参考收益、无风险利率、有效目标/市场收益、调整原因、阈值和代入公式。可导出目标计算CSV。

目标Beta = (有效目标收益 − 无风险利率) / (有效市场收益 − 无风险利率)。原有规则中，非正目标超额收益会调整为最低0.5个百分点；市场风险溢价低于0.5个百分点时，分母也会调整。这两项是现存业务政策，并非历史协方差估计。目标等于市场参考且未调整时，Beta自然为1；分子分母同时调整到0.5个百分点时也会为1。最小溢价调整可能产生0.58等其他值。本次没有为迎合手算结果替换政策或重写已批准记录。

年度市场参考收益采用匹配情景月份的月简单收益算术均值×12；目标分解展示各类资产的权重、参考收益、基准贡献、目标贡献以及股票需要补足的收益。新兴市场使用A股及港股的组合权重，不等同于纯港股。

实际回测Beta = 样本协方差(组合简单收益, 基准简单收益) / 样本方差(基准简单收益)。新回测将以下内容冻结到本次结果：

- 实际使用的共同周价格、实际交易日期、证券和基准权重、来源。
- 每期组合收益和基准收益、均值、协方差项、方差项、样本数。
- 复利累计收益、年化指数和最终收益、实际Beta。

回测使用每个观测区间恢复固定权重的模型，年化指数仍是52/观测区间数。若共同历史存在长假缺周，额外显示实际日历周跨度及按日历年化的比较值，明确两者差异；没有把一个旧模型结果静默替换为另一口径。推荐列表则按实际日历周计算复利年化，现在也可展开首尾价格和代入值。

可分别导出逐期收益CSV及冻结价格CSV，用Excel的协方差/方差或SLOPE计算复核。CSV保留未四舍五入的小数输入。历史回测若没有保存这些明细，界面明确提示无法重建原始证据，不使用今天的行情冒充旧输入。Sleeve历史步骤读取已保存的目标快照，避免全局数据变化后重新生成旧步骤的展示值。

手算测试覆盖Beta为2的三期收益、目标Beta为1的两种原因、最低溢价调整产生0.58、价格冻结及长假年化差异。线上测试人员提供的三种情景尚需使用对应档案CSV与其手算数据逐项对照；不能仅凭截图证明每一个线上数值已经完成业务验收。

## 2. 股票中文名称

推荐候选表在代码之前增加中文名称。优先使用组织股票库名称，缺失时退回原名称/代码，不自动编造译名。每只候选新增首尾调整价格、实际日历周跨度和累计收益，支持展开年化收益公式。

## 3. 可恢复删除档案

管理员可将非当前档案删除到回收站，或从回收站恢复；两项操作都校验当前登录密码。默认列表和复制来源不包含已删除档案，已删除档案不能选择、复制、启动正式流程写入或新研究任务。

组织锁、档案版本检查和运行中的研究/优化任务检查防止并发误操作。15分钟内5次错误密码后限制重试。审计记录保留动作、人员和档案版本，不记录明文密码。

本功能不物理删除审批、持仓、成交、报告、研究结果或审计。要删除当前档案，必须先切换到其他档案。原有“重置当前档案”功能保持独立语义。

## 4. 全市场目录与每日价格：本次实现的范围

“股票库”增加全市场目录区，使用EODHD已有连接，市场可选US、HK、SHG、SHE、TSE。提供：

- 指定市场完整目录后台同步，保存原始名称、代码、交易所、币种、证券类型，支持100条分页与名称/代码检索。
- 指定日期整市场收盘价批量同步，保存未复权收盘价和调整价格，按市场分别显示成功/失败。订阅不覆盖、空结果或非法日期不会用样本数据替代，也不会抹去上次有效价格。
- 每日自动同步可由管理员开启，默认关闭，默认运行小时为UTC 08:00。同步目录和前一个工作日的价格；休市仍可能无数据，任务明示失败后可人工选择有效日期重试。自动同步以服务持续运行和数据库可用为前提。
- 后台任务入库，操作去重、最多两个并行任务，网络处理有截止时间，服务重启后过期任务会标记失败。自动轮询状态不会延长闲置登录。

目录与“已核验推荐库”分别维护：目录同步避免逐只输入代码和名称；载入收录表后，仍需业务人员确认成长/价值风格并通过原有真实价格/交易所核验。系统不会根据名称猜测风格，也不会把未知分类证券自动用于正式推荐。

这是每日收盘数据，不是全市场盘中实时推送。整市场每日价格请求约消耗100次EODHD调用额度；实际权限、各交易所覆盖和费用需按账户许可验收。目录与每日行情的规模大，启用全市场长期留存前应核对数据库容量及备份安排。

接口依据：[交易所目录](https://eodhd.com/financial-apis/exchanges-api-list-of-tickers-and-trading-hours)、[每日批量行情](https://eodhd.com/financial-apis/bulk-api-eod-splits-dividends)。这两项不代表当前订阅已获得所有市场的实时授权。

## 5. 自动持仓取价和估值

监控页新增自动取价预览。后台每日批量价格同步也为监控中的正式档案生成预览。使用最近一次实际数量快照，优先读取批量缓存；未缓存的股票读取单股日线，日本市场使用现有Yahoo后备方案。估值使用未复权收盘价，外币股票以该日真实汇率换算到组合币种，不能把历史复权价格直接当作当日交易价格。

行情无法知道账户是否买卖、拆股或增加股份，因此预览不自动写入正式净值。执行人员明确确认数量在来源日至估值日仍然有效后，可保存当日持仓估值，无需手工输入每日价格。若数量改变，必须先更新实际持仓。

任一股票或汇率缺失时整组估值不能入账；预览版本、来源数量、当前档案和流程在入账时重新校验。已有正式估值不覆盖，已应用预览不能重复入账。自动估值证据保留本币价格、汇率、转换后单价/市值、来源和数量依据，正式持仓快照以组合币种表示。

本次没有自动推断交易、现金变动、股息或公司行动，也没有代用户执行证券交易。
